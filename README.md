# Drip

A coffee brew timer with a built-in ratio calculator. Static site, no build step.

- **Live app:** https://ilanis-agent.github.io/drip/app.html
- **Landing:** https://ilanis-agent.github.io/drip/

## Features

- 5 brew methods (V60, Chemex, French Press, AeroPress, Moka Pot) with classic doses and timed step schedules
- Ratio calculator: coffee dose drives water weight; Mild / Standard / Strong strength adjusts the ratio
- Brew timer with step-by-step guidance, water targets per pour, progress bar, pause/resume, and audio cues on step changes
- Last method, strength, and dose persist in localStorage

## Stack

Plain HTML/CSS/JS. `index.html` is the landing page, `app.html` is the app.
